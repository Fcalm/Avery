## 平台 v2 初次验收

2026-10-30，本地 Node.js v24.11.1 / Windows / Chromium 验证：

- 48 项规则、生命周期、HTTP、Runner、自定义案例及回归测试通过；22 个 JS 文件语法检查、控制端 TypeScript 接口契约检查通过。静态前端无编译构建步骤。
- 已复现旧评分缺陷：伪造描述、增加第三段项目、移除回执和事件仍为 58/58。根因是旧脚本只比对字段白名单与状态标记。新版该记录无认证分（`unverified`、`score:null`），并列出额外项目、自由文本、附件和回执问题。
- 评分回归覆盖同名经历串段、整体调换顺序、空第三段、额外选填、重复技能、原值误改、错误附件内容、未知文本改写、伪造事件、篡改结果及三个目标越界。

- 运行器的创建、同步、指标上报与结算错误归为环境失败，不计为 Agent 失败；包括执行器抛出空值的边界情况。

本轮浏览器是固定合成资料的脚本验收，不是 Avery 真实模型的网申能力成绩。Token 没有真实模型数据时保持 `null`。自由文本采用原文 / 白名单规则，不是开放语义评分；解析是确定性的行为仿真，不是真实 OCR。
