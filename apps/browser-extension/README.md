# Avery Browser

开发环境中打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式并选择“加载已解压的扩展程序”，然后选择本目录。

扩展只操作 Avery 创建并登记的任务标签页。关闭任务时只关闭该标签页，不关闭用户浏览器或其他页面。

配对成功后，浏览器已有其他标签页时自动关闭配对页。如果配对页是窗口中唯一的标签页，将其切换到空白页以保持浏览器运行。连接失败时保留页面显示错误。若用户已切换页面，保留用户当前页面。

快照节点身份在任务页的隔离执行世界中维护。更新扩展后请在扩展管理页点击“重新加载”；宿主会按协议指纹拒绝旧版 Service Worker。

握手、命令状态和结果请求最多等待 3 秒，长轮询最多等待 25 秒。截止时间覆盖响应体读取。结果传输失败时可以按原命令 ID 再发送一次已有结果，随后恢复轮询。
