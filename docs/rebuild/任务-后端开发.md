## 2. 任务清单

### B-01【P0】全量构建验证与 Electron 隔离冒烟

- **背景**：backend TS 重建（e330759）后未复跑过冒烟；根构建此前红（见前端 F-01）。
- **动作**：
  1. 前端 F-01 合入后执行 `npm run build` 全量，确认五个 workspace 包 + Vite 均绿。
  2. 复跑 Electron 隔离冒烟（Renderer 已加载、Backend 状态 `ready`、关键路由可用）。
  3. 行为对照抽查：新 `apps/backend/dist` 的 `host`/`router` 导出与 git 历史基线 `b493532` 中旧 dist 的契约面一致（输入、结果信封、错误码）。
- **验收**：全量构建绿；冒烟输出 `backend ready`；契约面对照无差异（差异需记录并评估）。
- **依赖**：F-01。
- **建议窗口**：0.5 天。
- **提醒**：若仍失败，把报错与根因写回 `docs/rebuild/PROGRESS-2026-08-20.md`，不得以"隐藏报错/重复刷新"掩盖。

### B-02【P1】里程碑 B 收口：lockfile、统一命令与 dist 策略

- **动作**：
  1. 生成并提交 `package-lock.json`（优先解决此前 npm 缓存权限问题；可参考 `origin/refactor/frontend-design-v2` 上已生成的 lockfile，但需核对与当前依赖一致）。
  2. 验证干净环境：`npm ci && npm run build` 通过（对应计划里程碑 B 验收标准）。
  3. 根 `package.json` 挂接统一命令：`test`、`smoke`（复用 `scripts/` 现有 16 个脚本）、`pack:win`。
  4. 执行 dist 跟踪策略（PM 已确认方向）：`git rm --cached` 移除 `apps/*/dist`、`packages/*/dist`，`.gitignore` 补规则；历史基线保留在 git 历史中可回查。
- **验收**：全新检出 `npm ci && npm run build` 通过；`npm test`/`npm run smoke` 可用；`git status` 无 dist 生成物噪声。
- **依赖**：B-01；与前端 F-02（design-v2 收敛，lockfile 来源）协调。
- **建议窗口**：1 天。

### B-03【P1】测试基建：Vitest + 后端领域单测

- **背景**：全仓库 0 测试文件，是当前最大技术债；里程碑 D 迁移时未做行为对照测试。
- **动作**：
  1. 引入 Vitest，建立 `tests/unit`、`tests/contract` 目录与 `npm test` 接线。
  2. 为 backend 重建模块补单测，优先：
     - revision / 资源锁：`resume-lock-store`、仓储层冲突路径；
     - 幂等：`idempotency-store`（重启后仍生效的持久化语义）；
     - 补偿与恢复：`workspace-operation-service`、`database-recovery-service`（迁移失败回滚、未知高版本 Schema 只读）；
     - 附件生命周期：引用计数、30 天保护期清理；
     - usage 归一与脱敏：Trace/日志写入前的 Key/Authorization/绝对路径移除。
  3. 行为对照：对迁移过的模块，用旧 dist（git 历史 b493532）作为对照基准补回归用例。
- **验收**：`npm test` 绿；核心领域模块关键路径有单测覆盖；脱敏、幂等、revision 冲突为必测项。
- **依赖**：B-01、B-02。
- **建议窗口**：2 天（与 B-04 并行推进后半段）。

### B-04【P2 · 主干】里程碑 E：Desktop/Preload TypeScript 重建

- **背景**：`apps/desktop` 仅剩恢复的 `dist`（package.json 声明了 build 但无 tsconfig/src，build 必失败）；`electron/preload.cjs` 仍为恢复 JS。行为基准：`apps/desktop/dist` 与 `electron/preload.cjs`。
- **动作**（按 ARCHITECTURE 阶段 B 与重建计划里程碑 E 顺序）：
  1. 新建 `apps/desktop/tsconfig.json` 与 `src/`（组合根）。
  2. **preload**：最小受限 `contextBridge`，方法一一映射固定 channel，不暴露原始 `ipcRenderer`。
  3. **gateway**：逐个恢复 IPC channel，输入校验、负载上限、限流、事件转发（含 `requestId`/`sessionId`）。
  4. **adapters**：文件选择、窗口控制、桌面能力（凭据走 `safeStorage`，唯一明文 Key 接触边界）。
  5. **main**：窗口创建、安全策略（`contextIsolation: true`、`nodeIntegration: false`、sandbox）、开发/生产加载、冒烟模式；`utilityProcess` 启动器按架构迁入 Desktop `backend-host`。
  6. 每迁移一个模块：与旧 dist 做输入/结果信封/副作用/失败行为对照；IPC 类型以 `packages/contracts` 为唯一来源。
- **验收**：`apps/desktop/dist` 与 `electron/preload` 均由仓库内 TypeScript 构建生成；IPC 契约测试通过（与 F-03 共同完成）；Electron 冒烟绿；旧 dist 在全部迁移完成前保留可回退。
- **依赖**：B-01、B-02；与前端 F-03 并行协作（消费侧核对）。
- **建议窗口**：3–5 天（建议拆分为 preload/gateway/adapters/main 四个提交，每个提交独立可验证）。
- **安全红线**：禁止为"先跑起来"开启 nodeIntegration 或放宽 sandbox；禁止同步 IPC。

### B-05【P2】里程碑 G · 数据侧：真实 usage 入库与 Trace 对账

- **动作**：会话 usage 持久化并在进入会话时立即恢复；Trace 与 UI 共用同一份 Provider usage 事实记录（不重复估算）；Provider 未返回 usage 时标记 `unavailable`，不得用本地估算入库冒充；历史会话重载恢复 usage 与项目环境，迟到事件不污染其他会话。
- **验收**：PRD 7.10 全部条目；真实请求后 UI、数据库、Trace 数值一致。
- **依赖**：B-04、F-04 联调环境；与前端 F-05、agent A-04 共同联调。
- **建议窗口**：1–2 天。

## 3. 提交与协作约定

- 提交格式 `type(scope): 中文说明`；B-04 每个模块一个提交（`refactor(desktop): 重建 preload` 等），禁止一次大提交。
- 生成物（`dist/`、`release-*/`）不入库；提交前 `git status`/`git diff` 检查，不得提交数据库、日志、凭据。
- 主进程不得承担长计算/阻塞 I/O；重任务转 Worker；异步优先，禁止同步 IPC。
- 行为对照测试（旧 dist vs 新 TS）是迁移验收的一部分，未对照不得宣称"已迁移"。
