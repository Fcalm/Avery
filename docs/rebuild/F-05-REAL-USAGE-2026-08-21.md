# F-05 前端真实 Usage 展示验收（2026-08-21）

> 状态：已完成 Renderer 消费侧与本地 Provider fixture 联调。
> 验收基线：PRD 7.10.1；会话状态由 `DesktopAgentBridge.GetSessionAssistantState` 提供。

## 交付结果

| PRD 要求 | 结果 | 实现与证据 |
| --- | --- | --- |
| 每会话独立恢复 | 通过 | `AssistantPage` 在切换会话时清空旧状态、递增版本号，并仅接收当前会话的返回。 |
| 最近一次 `prompt_tokens / context_limit` 百分比 | 通过 | 仅 `source: actual` 时以 `inputTokens`（最近一次 Provider prompt token）和 `contextLimit` 计算。 |
| 仅展示必要详情 | 通过 | Tooltip 仅包含 `prompt_tokens`、`context_limit` 和压缩阈值，不再显示累计输入/输出/消费或估算图表。 |
| Provider 未返回 Usage | 通过 | 显示“未知”，明确不使用本地估算。 |
| 新会话 | 通过 | 尚无成功或缺失 Provider 结果时显示“—”，不显示 `0%`。 |
| 非开发者用户可见 | 通过 | Usage 不再受开发者模式开关限制。 |

## 回归证据

- `tests/unit/frontend/usage-presentation.test.ts`：真实、Provider 缺失、新会话、历史估算 4 个展示状态。
- `tests/integration/agent/usage-reconciliation.test.ts`：Provider 返回的同一 Usage 事实进入会话展示源、持久化状态与 Trace。
- `tsc --noEmit -p tsconfig.json` 与 `npm run build:renderer`：通过。

## 数据语义

`inputTokens` 在会话状态中表示最近一次已完成 Provider 请求的 prompt token；`promptTokens`、`completionTokens`、`totalTokens` 为对账与观测字段，不用于用户 Usage 百分比，避免把累计值误作当前上下文占用。
