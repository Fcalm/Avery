## 2. 关键阻断（P0）：根构建失败

本次核验执行 `npm run build`：五个 workspace 包编译通过，**Vite 渲染进程构建失败**（此前记录「build 通过」基于原机器上磁盘残留文件，不代表本检出可构建）。

**根因**：`.gitignore` 中的 `workspace/` 规则无路径前缀，匹配任意层级的同名目录，导致 `src/features/workspace/`（前端工作空间 API 模块，含 `useWorkspaceData`、`workspaceData`、`mutationHelper`、`workspaceActions`）**从未被 Git 跟踪**；本工作区是 git 检出，该目录缺失。`src/app/App.tsx`、`AssistantPage.tsx`、`SettingsPage.tsx` 及 application/resume/settings/conversation/job/profile 各 feature 的 api 层（共 10 个文件）均引用 `../features/workspace/api/*`，Vite 解析失败即整体失败。

**关键事实**：该问题已有修复但滞留未合并——`origin/refactor/frontend-design-v2` 上的提交 `1dc13c5 fix(workspace): 恢复被 gitignore 误忽略的工作空间前端 API`。当前 `main` 与 `feature/backend-ts-rebuild` 均为「构建红」状态。

**影响**：应用不可构建、不可打包、不可冒烟；里程碑 E/F/G/H 全部被前置阻断。

**更新（B-01 执行）**：`feature/backend-ts-rebuild` 已合入 F-01（`d505508`）并复跑 `npm run build`，五个 workspace 包与 Vite 全部构建通过；此 P0 阻断在当前分支已解除。
