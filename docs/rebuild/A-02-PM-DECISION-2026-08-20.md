## 2. 岗位搜索范围裁决

### 2.1 Version 0.2.0

**不开放岗位联网发现，也不开放 URL 提取。**

- 岗位仍以用户手动录入为主。
- 默认场景不得注册或向模型暴露 `SearchJobs`、`ReadUrl`。
- 不允许后台搜索、定时搜索、翻页抓取、跨来源聚合或自动写入岗位库。

理由：0.2.0 的目标是恢复可维护、可构建的本地产品基线；`VERSION-ROADMAP.md` 已明确本版本不包含 URL 岗位提取。当前 Agent 仍有白名单、取消迟到事件、原子快照、AbortSignal、脱敏和待确认事实等已知安全差距，不能在这些门禁关闭前增加外部网络能力。

### 2.2 Version 0.3.0

只允许 **“用户提供明确 URL → `ReadUrl` 受限读取 → 展示提取结果 → 用户确认后入库”**。

- URL 必须由用户显式提供；Agent 不得自行搜索、猜测或扩展到其他来源。
- `ReadUrl` 仅允许公开 `http/https`，每次重定向重新校验；拒绝本机、内网、文件协议、携带凭据的 URL、Cookie 和登录态。
- 必须设置响应体、时间、重定向和内容类型上限；遵守站点访问限制，不绕过验证码、反自动化或登录验证。
- 提取结果默认只用于预览；用户确认后才通过独立窄写工具进入岗位库。
- 不计算岗位匹配分，不自动发起投递，不把简历全文或个人敏感信息拼入网络请求。
- `SearchJobs` 在 0.3.0 仍保持禁用，不进入默认场景白名单。

### 2.3 未来候选：有界按需岗位发现

产品原则上允许未来评估有界按需发现，但**本次裁决不形成版本承诺**。启用前必须另行更新 PRD 与路线图，并满足：

- 用户显式发起并给出岗位、地区、关键词等范围；仅在当前 Run 内执行。
- 只访问登记来源，通过 `SearchJobs`/`ReadUrl` 窄端口和固定预算执行。
- 禁止后台、周期性、无界翻页、持续监控和“扫描全网”。
- 结果仅为 Run 临时数据；保存岗位必须逐批预览确认。
- 无登录态、无 Cookie、无任意 HTTP、无浏览器控制、无验证码绕过。
- 先通过 SSRF、来源白名单、预算、取消、超时、脱敏、审计与条款合规专项验收。

**无界持续全网爬取永久属于非目标。**

## 3. 对 Agent 设计与实现的约束

Agent 开发执行 A-02 文档收敛时必须：

1. 将 `docs/Agent-design/README.md` 中“默认场景自主搜索岗位”改为版本化禁用说明。
2. 同步修订 `02-system-prompt.md`、`03-tools.md`、`06-harness.md` 及其他受影响文档；不得只修改 README。
3. 当前默认场景快照中不注册 `SearchJobs`、`ReadUrl`；模型请求未注册工具时必须由 Harness 拒绝。
4. `SearchJobs`/`ReadUrl` 的 Schema 可作为未来设计草案保留，但必须标记 `enabled: false`，不得进入生产工具清单。
5. 更新 PRD 只需消除歧义：保持“不自动扫描全网岗位”，并明确 0.3.0 仅支持用户 URL 提取；不要把未来候选写成已承诺功能。
6. 新增 ADR，记录当前禁用、0.3.0 URL 边界、未来有界发现候选与回退方式。

A-03 当前只修复既定安全与运行时差距，不实现 `SearchJobs` 或联网 `ReadUrl`；岗位网络工具不再是 A-03 的前置。
