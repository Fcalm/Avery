## 已复现并修复的隐患

| 隐患 | 修复 |
| --- | --- |
| 文本分字、分段插入，字符之间的过滤或焦点移动可能把后续内容写入另一字段 | 一次发送完整文本，仍检查原节点、焦点和实际值；不匹配时返回不确定状态，不自动重写 |
| 普通枚举使用子串匹配，可能把“党员”匹配为“预备党员”，或把不完整学校名匹配为另一所学校 | 普通候选采用等值与有限别名，移除“本科”推导“学士”；地区只保留层级导航匹配 |
| 民族、工作年限等候选可匹配，但最终回读使用不同规则，造成假失败 | 候选与回读复用同一组有限别名 |
| 自定义控件的原节点消失后，按序号回退到同名字段 | 有节点身份时只操作原节点，删除回退第一项逻辑；日期入口与回读也绑定原节点 |
| 回读父容器中的标签、相邻字段或菜单选项，以子串判定填写成功 | 通用动态选择后置校验只读取当前控件的业务展示值，Phoenix 不把内部搜索词当已选值；通用日期分支严格匹配完整值及来源精度 |
| 全页快照中的同名按钮混入动态候选 | 通用、Moka 和飞书候选均带内部标记，生产匹配只接受已标记候选 |
| 原生下拉、单复选框只回报已执行，不能发现事件处理后的回滚 | 原生下拉拒绝歧义及禁用选项，执行后独立回读；单复选框也核验真实状态；核验失败返回不确定状态 |
| 批量填写吞掉不确定错误，继续执行其他字段及关闭弹层 | 不确定结果向工具层传播并暂停，停止后续写入及弹层交互；候选引用的不确定失败也禁止自动重试 |

## 仍需针对平台复核

本次没有重放真实网申、上传或提交。地区弹层的选项识别、Phoenix 退出动画与虚拟列表重建、日期年份导航仍可能导致跳过或暂停。现有日志不足以还原组件的实际层级、动画和年份范围，不能宣称这些适配问题已经全部解决。

通用候选扫描仍依赖可见弹层特征；多个弹层同时存在、同名城市缺少省级路径、特殊控件未暴露真实展示值时，还需要进一步限制目标菜单和保留歧义。标记只排除了普通页面按钮，不构成所有 ATS 的完整适配证明。

单次动作成功只表示当次观察的字段状态；网站之后的异步解析、失焦校验或保存仍可能改变值。提交前应重新运行 `BrowserValidateForm`，核对保留值与来源，不能凭操作回执宣称整份网申正确。工具不能从不完整学校名称或省市信息推断缺失内容。
