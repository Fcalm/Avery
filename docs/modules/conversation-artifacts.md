# 对话产物卡片

- 最终报告完成后，产物卡片在报告下方纵向排列，不放入工作过程。
- 卡片展示资料名称、简历版本和增删行数；绿色 `+n` 表示新增，红色 `−n` 表示删除，零值省略。
- 按原始正文的换行统计，CRLF 与 LF 等价，末尾换行不额外算一行；内部空行计入行数。修改一行记为一增一删。
- 同一轮多次保存同一份资料，只展示最后保存的产物，行数比较本轮首次成功保存前与最后保存后的正文。
- 无变化、未确认、被拒绝及保存失败不生成修改卡片；只读资料仍可通过正文内链查看。
- 点击卡片使用现有资料侧栏。简历定位到卡片版本，编辑、撤销、保存、版本选择和下载入口沿用原功能。
- 增删行数随会话保存；等待确认或回答时的统计基线仅保存在宿主运行状态，重启续轮仍属于同一轮。
- 旧会话没有行数记录时保留已有产物入口，不补造统计。
