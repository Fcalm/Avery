# 首次使用引导

引导共 9 页，使用项目现有的松绿色、灰阶、字体、控件与窗口控制样式。

| 页码 | 内容 |
| --- | --- |
| 1 | 欢迎、昵称及可选求职偏好 |
| 2 | 连接模型、DeepSeek API Key 链接、测试与保存 |
| 3 | 建立真实经历档案 |
| 4 | 提问、附件与编辑权限 |
| 5 | 核对简历、设置当前版本、下载 PDF |
| 6 | 手动保存、自己设置条件采集、让 Avery 按要求采集 |
| 7 | 连接浏览器扩展、选择工作场景、人工接管 |
| 8 | 查看投递阶段、更新记录与下一步日期 |
| 9 | 开始整理档案或进入工作区 |

- 第二页可选择「稍后设置」。未连接模型时，可以先整理档案、手动保存或采集岗位；AI 功能仍需连接模型。
- DeepSeek 推荐链接为 https://platform.deepseek.com/api_keys，使用系统浏览器打开。
- 每页可返回上一步；教程可直接跳过。非敏感表单和进度自动保存，完成前会确认保存结果。
- API Key 只在表单内存与桌面端的加密配置中使用，不写入工作空间设置或引导草稿。更换服务商时清空输入框。
- 可选偏好仅用于创建缺失的求职意向；已有档案不会被覆盖。
- 教程配图来自真实 Electron 应用截图，示例资料为虚构内容。点击图片可放大查看。
- 完成后，从左下角账户菜单选择「重新查看使用教程」。重看从档案教程开始，不重复基础设置，不改动已有数据，也不卸载正在接收消息的对话页面。

配图位于 `public/assets/onboarding`，截图来源及裁切区域记录在同目录 `sources.json`。
