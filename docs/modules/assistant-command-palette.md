# 对话输入框命令面板

## 入口与交互

- 在整段消息句首输入半角 `/` 打开面板；光标后的正文不参与搜索。
- 英文命令名和技能名支持前缀筛选，`/skill` 只显示当前场景可用技能。
- 上下方向键选择选项，到边界停止；Enter 或 Tab 选择，不同时发送消息。
- Esc、点击外部、输入空格、移出句首命令片段时关闭面板，保留输入；关闭后按下方向键可重新打开。
- Shift + Enter 换行，Shift + Tab 离开输入区。输入法组词期间不打开面板或发送消息。
- 选择命令只消耗句首至光标的命令片段，后续文字、空格和换行保持原样。
- 模式和技能标签与首行正文同排，标签不进入正文。
- 技能标签不显示删除按钮；光标在正文句首且未选中文本时，按 Backspace 或 Delete 移除技能并保留正文。正文其他位置、文本选区和输入法组词继续使用原生删除行为。
- 压缩命令使用带 infinity 图标的独立高亮标签；正文句首按 Backspace 或 Delete 整块移除命令，后缀正文保持原样。
- 占位模式标签保留移除按钮，悬停或键盘聚焦时显示。

## 当前命令

| 命令 | 行为 |
| --- | --- |
| `/reload` | 确认后重载当前会话上下文和技能索引；取消或失败时保留完整输入，成功后仅移除命令片段。兼容原 `/reload-session` 入口。 |
| `/compact [instructions]` | 使用 infinity 图标和整块高亮标签，后缀保持普通正文。发送后命令进入对话区并清空已提交草稿，运行期间显示工作动画；完成后保留前后估算和摘要正文，失败或取消保留过程与回执。消息保存失败时保留草稿，不启动压缩。 |
| `/goal` | 目标模式占位，显示功能未完善提醒，不改变当前执行方式。 |
| `/<skill-id>` | 显式选择一个可用技能，重新选择时替换；可与一个占位模式标签并存。 |

## 技能与权限

- `agent:command-skills` 返回 `id`、`name`、`description`，不返回技能正文或磁盘路径。
- 已有会话读取其冻结的技能快照；新对话读取当前场景的注册表索引。
- 技能加载失败可在面板中重试，与无匹配结果分别显示。
- 用户选择的技能以 `AgentSendRequest.selectedSkillId` 传递，宿主按当前会话快照和场景校验。
- 指定技能不改变场景、确认策略、工具白名单或文件访问权限。
- 任务执行期间不能修改命令选择；等待确认仍属于当前任务。
- 压缩只允许空闲会话，不接受附件、技能或模式标签；命令与回执保存在可见对话中，不混入供模型继续业务的历史，也不自动续跑任务。
- 压缩沿用当前模型与思考设置，工具选择保持 auto；零次、多次或无效调用明确失败。原始后缀不直接发送摘要模型。
- 对话中的“压缩上下文”工具详情显示 Agent 整理后的要求、生成摘要的阶段和成功／失败结果；摘要正文直接保留在回复中，重进会话仍可查看。
- 对话轨迹记录命令、真实工具调用与回执、摘要及错误原因；上下文进度环等待下次业务请求的真实 usage，累计用量继续保留翻译和摘要请求的实际消耗。

## 新增命令

- 在 `src/features/assistant/composerCommands.ts` 中添加命令定义，包含名称、说明、图标、筛选词和动作。
- 新动作添加对应的类型化处理分支；面板、键盘导航和筛选逻辑共用现有组件。
- 新技能经技能注册表提供，前端自动生成菜单项；中文名称和简短说明可在 `SkillLabels` 中配置。
