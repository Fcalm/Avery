# 浏览器填写失败恢复与地区选择

更新日期：2026-11-10。

## 复现与定位

11 月 9 日 17:22 开始的网申请求 `request-7fd72945-cff4-461e-8047-c196314014ec` 在 17:25:19 暂停。Agent 在弹层搜索框输入“佛山”后，未完成地区选择，转而直接向籍贯入口 `@e147` 输入“广东佛山”。原节点的实际值未保留请求值，底层返回 `insert: value_mismatch`。旧工具层把该错误归为 `STATUS_UNKNOWN`，脚本第一步失败并直接暂停 Run。

本次独立空间观察发现，Phoenix 的籍贯入口包含 `.phoenix-select__input--unText`，该输入用于选择器焦点，不是自由录入字段。地区弹层初始只有搜索、取消、确认等内容，省市列表稍后才出现。旧流程的候选等待窗口较短，且北森适配器身份未完整进入正式字段模型。城市文字用于继续展开区县，旁边圆点才用于选中城市；优先点文字可能始终未提交所需层级。

上述结构和延迟在当前页面实际观察到；历史记录没有保存输入失败后的完整 DOM 状态，不能将某一种网站内部回滚机制认定为唯一历史根因。

## 恢复契约

- `BROWSER_FILL_VALUE_MISMATCH`：已核实原节点和焦点，但写入值未保留。停止脚本，返回 Agent 重新观察，不自动重写，也不继续后面的 Enter。
- `BROWSER_SELECT_REQUIRED`：识别到选择器专用输入，在清空或输入前拒绝，提示使用真实选项或 `BrowserFillForm`。
- 普通填写返回 `browserState.requiresSnapshot: true` 与 `recovery.action: observe_then_replan`，`replayAllowed: false`。Kernel 接收失败脚本携带的观察约束，禁止后续写入，直到新的快照成功。
- 高风险字段保持确认与暂停边界；提交、发送、上传、连接中断、焦点丢失或节点在写入后消失等真正不确定结果，继续使用原有保护。没有将所有 `STATUS_UNKNOWN` 改为可恢复，也没有自动重放脚本。
- 失败后的 Run 可以继续调用模型，但错误不是成功回执。Agent 必须核对保留值、区分输入和选择控件，仅规划剩余工作。

## 地区流程

北森身份随字段特征包传入 `FormField.interaction.adapter`，地区控件标为不可自由录入的级联选择器。生产驱动使用专用观察器：

1. 在工具剩余预算内，最多等待 8 秒，要求唯一地区面板、真实地区行以及稳定布局；不会把取消、清空、面包屑或页面正文当成地区选项。
2. 中间层点击文字展开；来源要求的最终层优先点击圆点选中，避免继续展开区县。
3. 需要确认时点击面板内的真实确认控件，随后回读原字段值。输入搜索词、浏览到城市列表、暂时选中或存在目标文字都不算填写完成。
4. 列表未就绪返回 `menu_not_ready`，多个面板同时可见时拒绝歧义，不猜测选项。保留原始节点身份和授权来源约束。

同步更新 Avery 的 `company-career-form` 场景指引：明确区分可恢复错误与真正未知结果，禁止直接填写选择器显示输入，普通文本填写不再默认追加 Enter。

## 验证与范围

- 修改前新增用例复现普通值不保留被升级为未知、选择器专用输入未拦截、失败脚本未携带重新观察约束。
- 覆盖 Kernel 多轮恢复：填写失败、盲目再次填写被阻止、重新观察、改用选择动作后完成 Run；同时覆盖高风险确认及未知状态暂停。
- 覆盖列表延迟 700 毫秒出现、列表持续为空、有多个地区面板，以及省份展开与城市选中动作区分。
- 在一个独立 ego 空间中，真实网申只打开地区入口并读取候选和结构，没有填写、上传或提交。新观察器实际识别出 36 个地区候选，其中包括广东省。
- 同一空间切换至本机页面，使用生产字段提取、审阅和 `BrowserFormDriver`，通过 DOM 命令适配器验证完整业务流程。列表延迟 750 毫秒出现，最终动作依次为“展开广东省、选中佛山市、确认”，回读值为“广东省/佛山市”。该验证覆盖地区业务逻辑，不等同于真实网站的完整原生鼠标投递流程。
- 21 个相关文件共 554 项检查、14 项后端检查通过，全部包构建及受影响类型检查通过。独立 ego 空间已关闭，本机页面服务已停止。
- 真实网站的网申完整填写仍由用户复核。新错误分类对更新后的执行生效，不修改历史暂停记录。
