## 已确认事项

- 北森科大讯飞公开端点可匿名访问；registerSystemInfo 返回 HTML 内 BSGlobal，而非直接 JSON。
- 科大讯飞列表响应同时有数字 JobAdId 与 UUID Id；应用链接应使用页面识别出的职位路由和 UUID，不把数字 ID 误当页面 ID。
- Moka 官方文档示例使用 Authorization，匿名能力须逐来源验证；不添加企业认证凭证。
- 提取率 40% 至不足 60% 仍为未通过 POC，继续修正与复测，不进入 Production MVP。
- 完整同步与增量同步分别标记；第一版只实现完整遍历，达到上限为 partial。
- 北森列表必须包含 DisplayFields，缺少时地点等字段会为空；明确职位 ID 与页面 UUID 各自用途。
- 任职要求缺失保持缺失，Moka 的完整 description 原样保留，不使用 LLM 推测事实。
- 岗位状态统一为 open/closed/unknown/stale，未知状态不作为可投递候选。
