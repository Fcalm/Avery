# OfferGet 前端设计规范（DESIGN）

> 版本：v2.0（信封 · 火漆 主题）
> 适用范围：Electron 桌面端全部界面（求职助手、岗位分析、简历管理、数据分析、设置、开发者模式）
> 本文件是界面实现的**唯一视觉依据**。当既有源码与本规范冲突时，以本规范为准，源码逐步收敛。

---

## 一、设计风格与主题

### 1.1 主题：「信笺 · 火漆」

视觉母题取自一只牛皮纸信封与黑色火漆印——OfferGet 的产品隐喻是"为你寄出一封得体的求职信"。

- **纸感底色**：界面像一张摊开的米色信纸，温暖、低刺激、可长时间阅读。
- **牛皮纸强调**：信封的牛皮棕作为品牌强调色，克制地出现在选中态、徽标与关键操作上。
- **火漆印收尾**：深咖近黑的"印泥"色承载正文与主按钮，像盖在信纸上的印章——重、稳、确定。
- **书信排版**：标题用宋体衬线，正文用黑体，中西文混排，保留书信的呼吸感与仪式感。

### 1.2 设计关键词

| 关键词 | 含义 |
| --- | --- |
| 温暖 | 全部颜色带暖调，禁止中性灰、冷灰、纯黑 |
| 克制 | 主色不超过 4 种，强调色只用在"需要被看见"的地方 |
| 书信感 | 衬线标题、宽行高、短行宽（正文栏不超过 720px） |
| 纸面层次 | 层级靠"纸张叠加"（底色差 + 细线 + 暖阴影），不用厚重投影 |

### 1.3 与旧版的差异（必须执行的迁移）

| 项目 | 旧版（已废弃） | 新版 |
| --- | --- | --- |
| 强调色 | 橙 `#C4530A` 系列 | 牛皮棕 `#C9A878` 系列 |
| 文字色 | 灰墨 `#5E574A / #787065` | 暖褐墨 `#6B5F4C / #978871` |
| 主色数量 | 橙 + 灰墨 + 纸色，体系松散 | 严格 4 主色 + 派生色 |
| 圆角 | 4/8/9/10/11/12 混用 | 仅 4/8/12/16/999 五档 |

## 二、设计规范

### 2.1 颜色规范

#### 2.1.1 四种主色（Brand Palette）

| 角色 | 名称 | 色值 | 使用场景 |
| --- | --- | --- | --- |
| 底色 | 纸米 Paper | `#F5EFE1` | 应用窗口背景、页面底色 |
| 强调 | 牛皮 Kraft | `#C9A878` | 品牌标识、选中态、激活导航左侧标记、徽标、进度、焦点环、关键数据的强调 |
| 墨色 | 深咖 Seal | `#2C251C` | 正文标题、主按钮底色、火漆印图形、重要图标 |
| 辅助 | 赭棕 Umber | `#8A6B45` | 次级强调：链接、hover 加深态、图表主系列、强调图标 |

> 主色到此为止。**任何第五种色相（橙、蓝、紫、翠绿等）都不得进入界面**；功能色见 2.1.4，只允许出现在状态提示中。

#### 2.1.2 派生中性色（由主色混合派生，不作为新主色）

| Token | 色值 | 使用场景 |
| --- | --- | --- |
| `--card` | `#FCFAF3` | 卡片、输入框、浮层表面（比底色亮半阶的"上层纸"） |
| `--paper-deep` | `#EDE5D2` | 凹陷区、控制台、代码块底、未激活开关 |
| `--line` | `#E2D8C2` | 分割线、卡片描边、表格线 |
| `--ink-body` | `#3D362B` | 正文（比标题浅半阶，降低长文压迫感） |
| `--ink-soft` | `#6B5F4C` | 次级文字：描述、表单项标签、导航未选中项 |
| `--ink-faint` | `#978871` | 占位符、时间戳、禁用态文字 |
| `--kraft-soft` | `#E9DCC2` | 强调色的浅底：选中导航背景、标签底、hover 态 |
| `--kraft-faint` | `#F4ECDC` | 大面积浅强调底：空状态插画底、推荐卡片 |

#### 2.1.3 功能色（仅状态语义，低饱和、暖调化）

| 语义 | 主色 | 浅底 | 使用场景 |
| --- | --- | --- | --- |
| 成功 Success | `#4F7A52` | `#E4EDE2` | 投递成功、余额正常、任务完成 |
| 警示 Warning | `#9A7422` | `#F3EAD0` | 配额将尽、待处理提醒 |
| 危险 Danger | `#A6452F` | `#F5E2DA` | 删除、不可撤销操作、错误提示 |

功能色文字/图标永远搭配同语义浅底使用，禁止把功能色大面积铺为背景。

#### 2.1.4 叠加与透明度

- 悬浮态：`color-mix(in srgb, var(--seal) 5%, transparent)`；强悬浮 8%。
- 遮罩：`color-mix(in srgb, var(--seal) 24%, transparent)`，弹窗/抽屉专用。
- 焦点环：`0 0 0 3px rgba(201, 168, 120, .35)`（牛皮棕 35%）。
- 所有派生必须用 `color-mix` 从主色生成，**禁止手写新的 hex**。

#### 2.1.5 颜色使用约束

- 对比度：正文/背景 ≥ 4.5:1；大字标题 ≥ 3:1。`--ink-faint` 只允许用于 12px 辅助文字。
- 牛皮棕 `#C9A878` 亮度高，**不得直接作为文字色**；需要强调文字时用赭棕 `#8A6B45`。
- 主按钮 = 深咖底 + 纸米字；牛皮棕不用于主按钮（对比度不足），只用于次级强调与状态标记。
- 阴影统一暖棕基色 `rgba(44, 37, 28, α)`，禁止灰色或黑色阴影。

### 2.2 字体规范

#### 2.2.1 字体家族（共 4 个，不得新增）

| Token | 字体 | 用途 |
| --- | --- | --- |
| `--font-serif` | Noto Serif SC / Source Han Serif SC / Songti SC | 页面标题、区块标题、书信感文案（信笺感的核心） |
| `--font-sans` | Noto Sans SC / PingFang SC / Microsoft YaHei | 正文、按钮、表单、导航等一切 UI 文字（默认字体） |
| `--font-mono` | JetBrains Mono / Cascadia Mono / Consolas | 代码、Token 用量、ID、等宽数字（`font-variant-numeric: tabular-nums`） |
| `--font-brand` | Playwrite DE LA Guides | 仅 "OfferGet" 品牌字标，**禁止用于任何其他文案** |

> 旧版 Nunito 仅限遗留开发者控制台沿用，新界面一律不再引入，随重构退役。

#### 2.2.2 字阶（Type Scale）

| 层级 | 字号 / 行高 | 字重 | 字体 | 使用场景 |
| --- | --- | --- | --- | --- |
| Display | 32 / 40 | 600 | Serif | 启动页、空状态主视觉标题 |
| 页面标题 | 24 / 32 | 600 | Serif | PageHeader 的 h1 |
| 区块标题 | 18 / 26 | 600 | Serif | 卡片组标题、抽屉/弹窗标题 |
| 卡片标题 | 16 / 24 | 600 | Sans | 卡片标题、列表主行 |
| 正文 | 14 / 22 | 400 | Sans | 默认正文、按钮、输入框 |
| 紧凑正文 | 13 / 20 | 400 | Sans | 导航项、表格、列表次级行 |
| 辅助文字 | 12 / 18 | 400 | Sans | 描述、时间戳、表单 hint |
| 标签 Kicker | 11 / 16 | 500 | Sans | eyebrow、徽标、分组标签；大写场景加 `letter-spacing: .12em` |
| 等宽 | 12 / 18 | 400 | Mono | 代码、用量数字、日志 |

#### 2.2.3 排版约束

- 字重只用 400 / 500 / 600 三档；Serif 标题不使用 700 以上。
- 中文正文行长控制在 28–48 字；阅读型栏宽容器最大 `720px`。
- 数字一律等宽对齐（表格、余额、Token 统计必须 `tabular-nums`）。
- `letter-spacing` 只允许出现在 11px Kicker（.12em）与品牌字（-.01em），正文不拉开字距。

### 2.3 网格与布局规范

#### 2.3.1 应用框架（桌面窗口）

| 区域 | 规格 |
| --- | --- |
| 基准窗口 | 1280 × 800；最小可用 960 × 640 |
| 侧边栏 | 默认 224px，可拖拽范围 192–320px；收起态 56px（仅图标） |
| 主内容区 | 最小宽 720px；求职助手场景最小 480px |
| 顶栏（Letterhead） | 高 56px，下方 1px `--line` 分隔线 |

#### 2.3.2 内容网格

| 项目 | 规格 |
| --- | --- |
| 列数 | 12 列（内容区 ≥ 1080px 时）；6 列（720–1080px）；单列（< 720px） |
| 水槽 Gutter | 24px |
| 页面边距 Margin | 32px；窗口 ≥ 1440px 时增至 48px |
| 内容最大宽 | 阅读型 720px；工作台型 1120px；超过后居中，不再拉宽 |
| 卡片栅格 | 卡片列表按 12 列均分：3 卡/行（各 4 列）、4 卡/行（各 3 列），水槽 24px |

#### 2.3.3 间距刻度（Spacing Scale）

只允许使用 4px 基数的刻度：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 图标与文字间：4 或 8
- 控件内部 padding：8 / 12 / 16
- 卡片内边距：20（紧凑）或 24（标准）
- 卡片之间：16（列表）或 24（栅格）
- 页面区块之间：32 或 48
- **禁止出现 5、7、9、10、13、14 等非刻度值**（旧源码中的 7px/9px/11px 圆角与间距需逐步归位）。

### 2.4 图标规范

#### 2.4.1 技术形态

- 统一使用 Iconfont 集合 16880 的 PNG 资源 + CSS mask 方案，颜色继承 `currentColor`，随场景自动适配墨色/牛皮棕/功能色。
- 新增图标必须来自同一集合，保持一致的描边粗细与圆头风格；禁止混入 emoji、彩色 SVG、其他图标库。

#### 2.4.2 尺寸刻度（仅 4 档）

| 尺寸 | 使用场景 |
| --- | --- |
| 12 | Kicker 标签内、徽标角标（尽量少用） |
| 16 | 导航项、菜单项、行内操作（重命名/删除）、表单内 |
| 20 | **默认尺寸**：按钮内、顶栏工具、卡片头部 |
| 24 | 空状态、功能入口大卡、启动页 |

#### 2.4.3 使用约束

- 同一容器内图标必须同一尺寸档位，垂直居中（flex `align-items: center`）。
- 图标与文字间距固定 8px（紧凑场景 4px）。
- 可点击图标必须有 32×32 的最小热区（可用透明 padding 扩展）。
- 图标默认取 `--ink-soft`，激活/强调取 `--seal` 或 `--umber`，禁止彩色图标（DeepSeek 品牌色除外，属第三方标识）。

### 2.5 模块规范

#### 2.5.1 圆角刻度（仅 5 档）

| Token | 值 | 使用场景 |
| --- | --- | --- |
| `--radius-mark` | 4 | 小标签、徽标、色块标记 |
| `--radius-control` | 8 | 按钮、输入框、下拉、导航项、小菜单项 |
| `--radius-card` | 12 | 卡片、消息气泡、思考块 |
| `--radius-overlay` | 16 | 弹窗、抽屉、用户浮层 |
| `--radius-pill` | 999 | 开关、进度条、滚动条、胶囊标签 |

品牌特例：`brand-mark` 使用 `9px 9px 4px 9px` 的不对称圆角（信封折角隐喻），仅限 Logo 图形，不扩散。

#### 2.5.2 核心组件规格

| 组件 | 规格 |
| --- | --- |
| 主按钮 | 高 36，padding `0 16`，圆角 8，深咖底 `#2C251C` + 纸米字 `#F5EFE1`，hover 上浮阴影 `--shadow-raised` |
| 次按钮 | 高 36，圆角 8，`--card` 底 + 1px `--line` 描边 + 墨色字 |
| 危险按钮 | 同次按钮结构，文字与描边用 Danger `#A6452F`，浅底 `#F5E2DA` |
| 输入框 / 下拉 | 高 40，圆角 8，padding `8 12`，`--card` 底，聚焦时 3px 牛皮棕焦点环 |
| 多行输入 | `line-height: 28`，最小 3 行 |
| 卡片 | 圆角 12，`--card` 底，1px `--line` 描边或 `--shadow-surface`，padding 24（紧凑 20） |
| 导航项 | 高 34，圆角 8，图标 16 + 文字 13/20；选中态 = `--kraft-soft` 底 + 深咖字 + 左侧 3px 牛皮棕标记 |
| 弹窗 Modal | 圆角 16，宽 480（表单类 560），24% 深咖遮罩 |
| 抽屉 Drawer | 圆角 16（左缘），宽 420，右侧滑入 |
| 开关 Switch | 32 × 18，圆角 999，激活底 = 牛皮棕 |
| 空状态 | 图标 24（`--ink-faint`）+ Display 衬线标题 + 14 辅助描述 |

#### 2.5.3 阴影刻度（暖棕基色 `44,37,28`）

| Token | 值 | 场景 |
| --- | --- | --- |
| `--shadow-surface` | `0 2px 8px / .06` | 卡片、顶栏工具 |
| `--shadow-raised` | `0 3px 14px / .09` | 悬浮卡片、hover 抬升 |
| `--shadow-overlay` | `0 13px 34px / .17` | 弹窗、抽屉、浮层菜单 |
| `--shadow-control` | `0 1px 3px / .25` | 开关滑块等小控件 |

#### 2.5.4 动效

- 标准过渡 `160ms ease`；浮层展开 `180–220ms ease`。
- 可动画属性仅限 `transform / opacity / background / box-shadow`，禁止动画 `width / height / top / left`。
- 页面级不做转场动画；抽屉/浮层沿进场方向位移 10px 内淡入。

## 三、设计约束（Do / Don't）

### 3.1 硬约束（违反即退回）

1. **颜色**：只允许 4 主色 + 派生 token + 3 组功能色；橙色、灰墨色、纯黑 `#000`、纯白 `#FFF` 一律禁用（卡片用 `#FCFAF3` 替代纯白）。所有颜色必须经 CSS token 引用，禁止硬编码 hex。
2. **字体**：只允许 4 个字体家族与 9 档字阶；品牌手写字仅用于 Logo；Nunito 不再进入新界面。
3. **间距/圆角**：只用既定刻度；新增组件前先查刻度表，查不到才允许扩展（并在本文件登记）。
4. **主色克制**：牛皮棕强调色在单屏出现不超过 3 处；一屏只有一个主按钮。
5. **可访问性**：正文对比度 ≥ 4.5:1；可点热区 ≥ 32×32；焦点环不可移除；`prefers-reduced-motion` 时关闭非必要动效。

### 3.2 软约束（评审关注点）

- 优先用"纸张明度差 + 1px 细线"分层，慎用阴影；同一视口阴影层级不超过 2 层。
- 长列表、日志、控制台等密集信息场景用 `--paper-deep` 凹陷底收敛视觉，而非加边框。
- 文案遵循书信语气：简短、礼貌、确定；按钮用动宾短语（"保存""投递""新建会话"），不用"好的""确定"。
- 第三方品牌元素（DeepSeek 标识等）保留其原始色彩，不套用火漆色板。

### 3.3 迁移路线（源码向本规范收敛）

1. `tokens.css` 整体替换色板：accent 系列由橙改为牛皮棕，ink-soft/faint 由灰墨改为暖褐墨，focus-ring 同步换色。
2. 全局替换圆角与间距的非刻度值（9/10/11px 圆角 → 8/12/16）。
3. 字阶收敛：`--text-body 15px` 并入 14，`--text-ui 14` 视密度并入 13 或 14。
4. 开发者模式界面最后迁移，期间允许保留旧字体与灰阶，但颜色仍须换板。
