# Avery 前端设计规范（DESIGN）

> 版本：v4.2（低圆角浅绿工作台）
> 适用范围：Electron 桌面端全部界面（求职助手、岗位分析、简历管理、数据分析、设置、开发者模式）
> 本文件是界面实现的唯一视觉依据。现有实现与本规范冲突时，以本规范为准，并通过设计 token 与既有组件逐步收敛。

---

## 一、设计风格与原则

### 1.1 主题：浅绿玻璃工作台

Avery 是一套面向桌面任务流的轻量工作台：低饱和浅绿渐变提供空间感，半透明玻璃容器组织功能，黑白控件给出明确的操作层级。整体应显得干净、轻盈、克制，而不是堆叠装饰性效果。

| 关键词 | 设计含义 |
| --- | --- |
| 低饱和 | 页面背景只使用浅绿渐变，避免高饱和大面积色块。 |
| 玻璃质感 | 导航、工具栏与次级容器使用半透明白色和背景模糊，形成通透层级。 |
| 高对比操作 | 当前导航与主操作使用黑白高对比，确保关键操作一眼可辨。 |
| 同色系标签 | 状态、筛选与辅助信息优先使用“浅色背景 + 同色系深色文字”的标签，而非仅以黑白灰区分。 |
| 低圆角 | 结构容器、卡片与工作区使用直角；仅紧凑控件、浮层和标签使用 4px 低圆角。圆形仅用于头像、进度环等有明确语义的元素。 |
| 留白 | 用充足的页面边距和卡片间距组织信息，避免密集分割线。 |

### 1.2 适用基准与响应式策略

- 基准画布为 1920 × 1080 的 16:9 桌面窗口；页面以工作台布局而非移动端页面为目标。
- 窗口宽度为 1440px 时，收紧内容区与卡片内边距，但保留 16–24px 的主要间距。
- 窗口宽度低于 1100px 时，优先收起或折叠侧边栏；不允许仅靠压缩文字和图标维持布局。
- 主内容区支持滚动，窗口根层背景固定；非必要的玻璃模糊不得叠加在长列表的每个条目上。

## 二、设计 Token

### 2.1 颜色

所有业务界面必须通过 CSS 自定义属性引用颜色；禁止在组件样式中新增与本表等价的硬编码颜色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-bg-start` | `rgba(236, 245, 228, .85)` | 根层渐变起点 |
| `--color-bg-end` | `#CBE3BC` | 根层渐变终点 |
| `--color-surface-glass` | `color-mix(in srgb, var(--color-surface-card) 35%, transparent)` | 全部导航、工具栏、浮层与次级玻璃容器 |
| `--color-surface-card` | `#FFFFFF` | 内容主卡片与需要最高可读性的实体表面 |
| `--color-surface-workspace` | `#EEF4EA` | 主内容工作区的无效果实色表面 |
| `--color-border` | `#C6C6C6` | 卡片与控件常规描边 |
| `--color-border-glass` | `rgba(255, 255, 255, .40)` | 玻璃表面描边 |
| `--color-text-primary` | `#000000` | 主标题、关键图标、深色控件上的反白基准 |
| `--color-text-secondary` | `#696969` | 说明文字、未选中导航与次要图标 |
| `--color-brand-soft` | `#FBF4D5` | 温和强调、推荐提示与非破坏性状态底色 |
| `--color-control-dark` | `#000000` | 选中导航、黑色主控件 |
| `--color-control-light` | `#F3F3F1` | 浅灰工具按钮 |
| `--color-tag-surface` / `--color-tag-text` | `#E4EFE7` / `#2F7A4D` | 通用浅绿标签背景与文字；状态、筛选和辅助元数据优先复用 |
| `--trace-role-system-surface` / `--trace-role-system-text` | `#F3F3F1` / `#5F5F5F` | 轨迹 System 角色小卡片 |
| `--trace-role-user-surface` / `--trace-role-user-text` | `#E4EFE7` / `#2F7A4D` | 轨迹 User 角色小卡片 |
| `--trace-role-tool-surface` / `--trace-role-tool-text` | `#F7ECD3` / `#96660B` | 轨迹 Tool 角色小卡片 |
| `--trace-role-assistant-surface` / `--trace-role-assistant-text` | `#EEE9FB` / `#66519C` | 轨迹 Assistant 角色小卡片 |

```css
--app-background: linear-gradient(
  135deg,
  rgb(220 235 212 / 75%),
  rgb(142 199 122 / 75%)
);
```

- 根容器使用 `--app-background`，且背景固定、不随内容区域滚动。
- `#000000` 仅用于高对比文字、深色控件和其反白内容；不可大面积铺设为页面背景。
- 单个页面最多使用三种颜色家族：中性色、页面强调色及必要的语义反馈色。强调色应覆盖该页面的标签、筛选、统计数字和辅助状态，禁止同页并列使用无关的黄、蓝、紫、红色标签。
- 标签必须使用同一色相的浅色背景与深色文字；仅依赖颜色传递的状态仍须保留文字、图标或数值说明。
- 语义反馈（成功、警告、错误）可保留既有语义 token，但仅用于状态本身，不能替代本规范的主视觉色。
- 文字与实际承载底色的对比度：正文不低于 4.5:1，大号文字不低于 3:1。

### 2.2 表面、描边与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-container` / `--radius-card` / `--radius-surface` | `0` | 应用外壳、工作区、内容卡片与结构分区 |
| `--radius-control` / `--radius-overlay` | `4px` | 常规按钮、输入框、小型菜单与浮层 |
| `--radius-mark` | `0` | 行内标记、列表行与紧凑分隔块 |
| `--radius-pill` | `4px` | 状态标签、筛选标签与紧凑导航项；名称仅为兼容既有组件 |
| `--blur-glass` | `22.5px` | 玻璃导航、顶栏与浮层 |
| `--blur-app-shell` | `var(--blur-glass)` | 应用外壳玻璃层，与其他玻璃表面保持一致 |
| `--shadow-glass` | `2px 2px 10px -1px rgba(0, 0, 0, .25)` | 玻璃面与应用外壳的轻量立体感 |

玻璃表面的标准构造：

```css
background: var(--color-surface-glass);
border: 1px solid var(--color-border-glass);
border-radius: var(--radius-container);
backdrop-filter: blur(var(--blur-glass));
box-shadow: var(--shadow-glass);
```

- 内容主卡片使用白色实体表面、`1px solid var(--color-border)` 和直角；所有导航、工具栏、浮层与次级玻璃容器统一使用上述 35% 白色透明磨砂玻璃，不得混用其他透明度、模糊强度、描边或阴影。浮层可使用 `--radius-overlay` 的 4px 低圆角。
- 不通过多层重阴影制造层级；同一视口的阴影应保持轻、少且一致。
- 当 `backdrop-filter` 不可用或用户启用减少透明度时，玻璃表面回退为接近白色的实底，并保留描边与信息层级。

### 2.3 字体与排版

| Token | 字体栈 | 用途 |
| --- | --- | --- |
| `--font-ui` | `SF Pro Display, PingFang SC, Microsoft YaHei, sans-serif` | 默认 UI、正文、表单与按钮 |
| `--font-heading-serif` | `Noto Serif SC, Source Han Serif SC, Songti SC, SimSun, serif` | 内容标头中居中的具体场景名称 |
| `--font-nav` | `var(--font-sans)` | 左侧导航文字，使用无衬线常规字重 |
| `--font-mono` | `SFMono-Regular, Cascadia Mono, Consolas, monospace` | 代码、标识符、等宽数字 |

| 层级 | 字号 / 行高 | 字重 | 场景 |
| --- | --- | --- | --- |
| 展示标题 | 32–48 / 1.2 | 600–700 | 首页主标题、空状态主标题 |
| 页面标题 | 24–32 / 1.25 | 600 | 页面抬头与主工作区标题 |
| 区块标题 | 18–24 / 1.35 | 600 | 卡片组标题、面板标题 |
| 正文 | 16 / 1.5 | 400 | 说明、表单和主要内容 |
| 辅助文字 | 12–14 / 1.5 | 400 | 时间、状态和补充说明 |
| 导航文字 | 16 / 1.25 | 400 | 左侧导航、当前工作区入口 |

- 业务 UI 不再使用手写体作为正文或标题。Avery 标识如使用定制字，仅限 Logo 区。
- 数字、ID、时间和代码使用 `--font-mono`，并启用 `font-variant-numeric: tabular-nums`。
- 文本溢出时优先使用单行截断与省略号；不得让标签、工具栏或导航项因为长文本撑破布局。

### 2.4 间距与布局

| Token / 规则 | 值 | 使用方式 |
| --- | --- | --- |
| 页面外边距 | `16–24px` | 应用壳与视口、主要区域之间 |
| 主内容内边距 | `24–32px` | 页面内容区、工作区卡片 |
| 网格间距 | `16–24px` | 卡片、模块和栏位之间 |
| 侧边栏宽度 | `260–280px` | 1920px 基准窗口下的展开态 |
| 顶部工具栏高度 | `40px` | 窗口控制区域，图标背景使用 40 × 40px 正方形热区 |
| 内容卡片最小高度 | `280px` | 独立内容区或数据模块 |

- 窗口控制栏、侧边栏和主内容玻璃板与应用边缘、以及彼此之间的间距统一为 `8px`；此规则不影响内容区内部的页面边距与卡片间距。
- 求职助手对话卡片与右侧内容卡片之间保持 `8px` 留白，不使用可见分隔条；如支持拖拽调宽，热区必须透明并覆盖在该留白内。
- 主要内容区使用 `minmax(0, .8fr) minmax(0, 1.2fr)` 作为非对称双栏的默认比例；窄窗口改为单列或折叠次栏。
- 主容器均为直角，并用 16–24px 间距分隔；不要用密集边框代替留白。
- 所有可收缩的 flex/grid 子项必须允许 `min-width: 0`，保证长标题、标签文本和工具栏能正确截断。

## 三、组件规范

### 3.1 导航与应用外壳

- 左侧栏是浅色玻璃容器，展开态宽 260–280px；收起态固定为 56px，仅保留 Avery Logo、账户头像与一级导航图标（配合悬浮提示），隐藏品牌文字、账户文字、分组标题、历史会话与次级操作。展开和收起仅过渡宽度、内边距与透明度，时长 160ms；收起态一级入口为居中的 40px 方形低圆角图标按钮，纵向按 8px 间距排列。
- 导航选中态为黑色低圆角背景、白色文字，最小高度 42px；未选中态为透明背景与黑色文字。
- 导航字体使用 `--font-nav` 的无衬线常规字重；图标与文字间距 8px，保持同一视觉重量。
- 应用根壳、侧栏和主要工作区采用直角边缘。窗口内区域可按布局要求贴合应用边缘，不额外添加外壳圆角。

### 3.2 顶栏、标签页与工具按钮

- 内容与标签顶栏高度为 40px，采用玻璃表面。标签栏与右侧窗口/面板工具必须是两个独立布局区域。
- 窗口控制栏高度为 40px，横向贴合应用边缘，并与下方工作区相连；左侧展示 Avery 图标与文字，图标悬停时切换为导航栏展开/收起按钮，右侧保留窗口控制按钮。所有顶栏图标背景均为相连的 40 × 40px 无圆角正方形，不展示其他文本或标语。
- 内容区标头不显示日期或星期。求职助手的右侧栏展开、收起与放大按钮属于标头工具组，固定在同一 X 坐标，工具组右缘与应用顶部控制栏的按钮右缘对齐，不因右侧栏的打开或展开改变位置。
- 求职助手标头中央显示当前会话标题，使用无衬线字体；标题与下拉图标组成会话切换按钮。会话菜单在该按钮正下方居中展开，采用独立的 35% 白色透明磨砂玻璃浮层，不复用普通白色下拉菜单的实体表面样式。求职助手在标头左侧提供仅含图标的对话、轨迹视图切换按钮，默认显示对话；左侧切换器与右侧标头工具组到内容玻璃板边缘的间距相同。轨迹视图只显示当前对话的请求轨迹；尚未建立当前对话时显示空状态，不显示、也不能切换到其他会话或删除操作。
- 标签页使用浅灰实体底、4px 低圆角；标签宽度须设定最小值和最大值，并在可用空间内弹性分配。标题必须 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`。
- 标签页关闭按钮必须位于标签自身的裁剪与圆角范围内；悬停底色不可溢出标签页边界。
- 新建标签按钮紧贴标签列表的右侧，随标签列表布局流动；它不属于顶栏最右侧的全局工具区。
- 展开侧栏、放大面板等全局工具固定在工具栏右端，不得随标签宽度变化而位移。
- 所有图标按钮最小热区为 32 × 32px。**位于玻璃背景上的按钮一律默认透明背景、黑色图标；悬停、按下或键盘焦点选中时切换为白色背景和黑色图标。** 此规则适用于窗口控制、侧栏展开、面板工具与玻璃工具栏中的全部图标按钮；不以危险色覆盖窗口关闭按钮的选中态。

### 3.3 下拉菜单与浮层

- 菜单以触发按钮为锚点，在新建标签按钮的左下方展开，保证菜单右缘优先落在应用可视区域内。
- 浮层定位必须在渲染后根据可视区域进行碰撞检测：空间不足时向左或向上翻转，禁止内容超出应用边界。
- 菜单使用玻璃或白色实体表面、4px 容器低圆角和统一轻阴影；菜单项保持足够点击热区，不贴近容器边缘。
- 会话切换菜单与 Todo 展开列表使用统一的透明磨砂玻璃：`background: var(--color-surface-glass)`、`1px solid var(--color-border-glass)`、`backdrop-filter: blur(var(--blur-glass))` 和 `--shadow-glass`。它们必须覆盖在原内容之上，使底层对话或界面能够模糊透出；动画只改变高度、透明度和位移，不插入或过渡白色实体背景。
- 所有下拉控件与菜单使用项目统一组件，容器均为 `1px solid var(--color-border)` 灰色描边和圆角；当前选项、悬停项与键盘焦点项统一使用 `--color-control-light` 灰色背景。不得使用系统原生下拉菜单的默认蓝色选中态。
- 浮层打开和关闭仅动画 `opacity` 与 `transform`，时长 160–220ms；支持键盘焦点与 Escape 关闭。

### 3.4 内容卡片、按钮与输入

- 内容卡片为白色实体表面，最小高度 280px，直角，描边使用 `--color-border`；卡片内边距 24px（密集内容可为 20px）。
- 主要操作用黑色实心按钮配白色图标/文字；次要操作使用浅灰或透明玻璃按钮，禁止同屏出现多个相互竞争的深色主按钮。
- 搜索与筛选输入使用 4px 低圆角，基准高度 32px；表单输入使用 4px 低圆角和 40px 高度。
- 输入框、文本域与下拉控件聚焦时保持常规描边，不额外显示灰色焦点描边或阴影。
- 图标按 16 / 20 / 24px 三档使用；同一容器内图标尺寸必须一致。
- 筛选、状态和辅助元数据优先使用低圆角标签：背景使用 `--color-tag-surface`，文字使用 `--color-tag-text`，高度 20–28px；选中态可增加同色系描边，不改用黑色或白色反转。页面内所有非语义标签必须共用同一强调色系。
- 投递管理使用“概览与筛选 + 列表 + 详情”的工作台布局：概览卡片整合统计、状态标签、搜索和新增操作；下方以 8px 间距分成左侧投递列表与右侧详情内容卡片。点击列表仅切换详情，编辑、推进和删除必须由详情区的明确操作触发。列表与详情各自滚动，页面根层不因记录数量产生滚动条。
- 岗位库由两张同级内容卡片构成，并与内容玻璃背景保持 `8px` 间距；首张卡片上缘紧贴标头下边界。上方卡片左侧竖排显示“近两周投递情况”，右侧显示最近 14 天的每日投递柱状图：不显示 Y 轴，柱默认灰色，悬停改为黑色并展示具体数值。图表下方提供渠道、投递情况、匹配度、收藏情况四个统一下拉筛选控件，以及重置筛选按钮；所有控件遵循常规按钮与下拉的圆角、灰色描边、灰色选中态规范。下方岗位卡片填满剩余可用高度，底部距离玻璃背景 `8px`；根页面不滚动，仅岗位列表在卡片内部滚动。列表按每页 50 条惰性渲染，接近底部时追加下一页。卡片左上角只显示“当前显示 n 个岗位”和“已投递数量”，投递数值使用大字号的 `--success` 绿色；右上角放置仅含图标的新增按钮。具体岗位使用单列全宽、低高度的横向长条卡片，只展示企业名称、岗位名称、城市、薪资、经验与“匹配分 + 数值”，且每项占用独立信息列。右端为编辑、投递、收藏三枚等宽横向操作按钮；岗位编辑仅由编辑按钮进入。岗位条内边距为 `8px`，桌面端高度为 `50px`（32px 图标按钮加上下各 8px 留白及描边），描边必须完整包裹全部字段与操作位。

### 3.5 右侧浏览器/面板工作区

- 浏览器与其他右侧面板以标签页承载，每个标签都对应独立的面板实例与状态；新建标签必须创建并激活新实例，不能覆盖原面板。
- 标签列表可横向滚动，但新建按钮与全局工具不随滚动列表漂移；长标签标题仅截断文本，不改变标签最大宽度。
- 面板空状态、加载状态与失败状态必须清晰区分，并提供可恢复操作；不得因加载失败而让整个标签栏或右侧工作区消失。
- 浏览器运行状态提示、登录数据清除与其他维护操作集中放在设置中的“浏览器设置”次级页面；对话界面只保留任务与浏览器投递交互，不展示维护提示或清除数据按钮。清除独立浏览器登录数据必须经不可逆操作确认，且明确说明不会影响系统浏览器。
- 求职助手右侧栏只承载简历内容卡片；不保留内置浏览器的顶栏、标签页、地址栏或前端网页视图。隔离浏览器仍作为投递场景的独立运行能力存在，不通过右侧栏嵌入。右侧内容卡片使用 `--color-surface-card`、`1px solid var(--color-border)`、`--radius-card` 与 `--shadow-surface`，其正文区域必须填满卡片可用宽度。
- 右侧简历栏底部采用紧凑操作条：操作条内边距为 `8px`，按钮与操作条边缘保持 `8px` 间距。操作条不使用圆角或灰色背景，而使用 `1px solid var(--color-border)` 上描边与正文分隔。左侧使用简历切换下拉按钮，菜单向上展开；菜单项仅展示简历标题前 8 个字符，编辑、撤销、保存按钮与其保持同一 Y 轴。
- 简历预览允许安全渲染基础 HTML（标题、段落、列表、表格、强调与安全链接）；脚本、样式、嵌入内容、事件属性和非 `http`、`https`、`mailto` 链接必须在渲染前移除。编辑态展示原始 HTML 文本。

### 3.6 求职助手聊天卡片

- 求职助手对话主区直接使用工作区表面，不再使用外层白色内容卡片；输入框与消息等交互层按自身组件规范承载。若独立白色内容卡片仍有必要，使用直角与 `1px solid var(--color-border)`，不以阴影区分层级。
- 卡片上缘与内容标头下缘相连，左、右、下缘与内容玻璃背景各保留 `8px` 间距；聊天列表和输入区在卡片内部滚动与排布。
- 用户消息气泡、Markdown 代码块和反引号包裹的行内代码使用 `--color-bg-end` 浅绿底；代码块内部代码继承代码块底色。聊天输入框使用不透明 `--color-surface-card` 白色实体表面、`1px solid var(--color-border)` 描边与直角，不使用玻璃模糊或阴影。
- AI 思考摘要只展示“思考内容”和紧邻右侧的展开图标，不展示辅助展开文案。

### 3.7 轨迹事件标识

- 轨迹事件不使用独立圆点或分隔装饰；角色以紧邻事件摘要的小型低圆角卡片表达。
- 小卡片使用角色对应的前景与背景 token：System 为中性灰，User 为浅绿，Tool 为浅黄，Assistant 为浅紫。角色名使用 `--font-mono`、全大写或既有角色名，不以颜色承载唯一语义。
- 每轮分组标题使用 `TURN-n`，不展示或提供复制内部 Request ID 的入口。每条轨迹事件使用 4px 低圆角和完整的 `1px solid var(--line-subtle)` 描边；展开内容沿用同一卡片的下低圆角。
- 求职助手的轨迹视图不复用聊天主卡片作为外层白底。轨迹元数据（时间、模型、请求数量、场景、搜索与筛选）与轨迹事件列表分别承载于两张同级的白色内容卡片，两张卡片均使用 `1px solid var(--color-border)`、直角和无阴影，并以 8px 留白分隔。信息卡片固定在顶部，仅下方事件列表可滚动；信息卡片中的搜索框和筛选控件同样使用 `1px solid var(--color-border)` 描边。
- 轨迹信息卡片中的搜索框与筛选控件高度统一为 40px。筛选除角色外还提供 `Success` 与 `Failed`，分别按事件成功和失败状态过滤。

## 四、可访问性与性能约束

1. 所有可点击控件至少提供 32 × 32px 热区、可见键盘焦点和明确的 `aria-label`。
2. 在 `prefers-reduced-motion` 下禁用非必要的进入、悬停和位移动画；在 `prefers-reduced-transparency` 下使用实底回退。
3. 玻璃模糊只用于应用壳、导航、顶栏和少量浮层；滚动长列表及高频更新区域应使用静态实体表面，避免 GPU 压力和滚动卡顿。
4. 不为纯视觉效果引入新的图标库、字体库或运行时依赖；优先复用项目既有图标组件和 design token。

## 五、实施与验收清单

### 5.1 Token 迁移

1. 在 `src/styles/tokens.css` 中以本规范的 `--color-*`、圆角、模糊和阴影 token 为单一来源，保留旧 token 的兼容映射仅作为过渡。
2. 先迁移应用根背景、应用壳、侧栏和顶栏，再迁移内容卡片、浮层和局部控件。
3. 组件中不得复制渐变、玻璃参数或颜色值；需新增视觉值时，先补充本规范和 token 定义。

### 5.2 视觉验收

- 在 1920 × 1080、1440px 宽度和小于 1100px 宽度下检查导航、顶栏、标签栏与双栏工作区。
- 检查长标题、多标签、单标签、空标签和关闭按钮悬停状态，确保不溢出、不遮挡、不错误位移。
- 检查新建标签菜单在右侧边缘附近的展开方向，确保完整留在应用内。
- 检查玻璃降级、键盘导航、焦点环和高对比文字；对涉及右侧浏览器的改动，验证独立面板创建、切换、关闭和加载失败回退。
