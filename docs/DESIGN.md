# OfferGet 前端设计规范（DESIGN）

> 版本：v3.1（云上 · 朝晖 主题）
> 适用范围：Electron 桌面端全部界面（求职助手、岗位分析、简历管理、数据分析、设置、开发者模式）
> 本文件是界面实现的**唯一视觉依据**。当既有源码与本规范冲突时，以本规范为准，源码逐步收敛。

---

## 一、设计风格与主题

### 1.1 主题：「云上 · 朝晖」

视觉母题取自日出时分的天空与晨光中的陶砖——界面像一扇朝向朝霞的玻璃窗，所有内容浮在玻璃之上，温暖、通透、层次分明。

- **朝霞为底**：窗口背景是一片 160° 固定渐变（鲑粉 → 蜜桃 → 米白），不随内容滚动，营造空间纵深。
- **玻璃为器**：一切卡片、导航、浮层都是半透玻璃（白色叠底 + 背景模糊），透过表面始终能看到霞光。
- **透明度即层级**：层级不靠颜色差与阴影堆叠，靠玻璃透明度——承载越重要的内容，越不透明。
- **一色点睛**：全界面只有砖红一种主色，像晨光里最先被照亮的一面陶砖墙，只落在需要被看见的地方。

### 1.2 设计关键词

| 关键词 | 含义                                             |
| --- | ---------------------------------------------- |
| 通透  | 所有表面半透明，背景渐变始终隐约可见                             |
| 克制  | 主色仅 1 种，强调只出现在选中态与关键操作                        |
| 轻盈  | 层级用透明度差与 1px 玻璃描边，不用厚重投影                      |
| 清晰  | 文字区保证模糊兜底与对比度，通透不以牺牲可读性为代价                    |

## 二、设计规范

### 2.1 颜色规范

#### 2.1.1 唯一主色（Brand Color）

| 角色 | 名称       | 色值        | 使用场景                                          |
| --- | -------- | --------- | --------------------------------------------- |
| 主色 | 砖红 Brick | `#B34F4F` | 主按钮底色、选中态、激活导航标记、链接、焦点环、进度、徽标、关键数据强调         |

> 主色到此为止。**任何第二种色相（蓝、紫、橙、翠绿等）都不得进入界面**；语义色见 2.1.5，只允许出现在状态提示中。

#### 2.1.2 背景渐变（窗口级，固定不滚动）

| Token      | 值                                                              | 说明          |
| ---------- | -------------------------------------------------------------- | ----------- |
| `--bg-sky` | `linear-gradient(160deg, #EFBEB4 0%, #F7D7C3 50%, #FBEEDD 100%)` | 应用窗口根层唯一背景 |

- 渐变铺设在窗口根层（`body` / 根容器），内容滚动时背景保持静止。
- 任何页面、区块、卡片不得再绘制不透明底色覆盖渐变。

#### 2.1.3 玻璃表面（四档透明度 = 四个层级）

所有表面统一构造：白色半透明叠底 + `backdrop-filter: blur(16px)` + 1px 玻璃描边 `rgba(255,255,255,.6)`。

| Token             | 叠底                      | 使用场景                    |
| ----------------- | ----------------------- | ----------------------- |
| `--glass-overlay` | `rgba(255,255,255,.85)` | 弹窗、抽屉、浮层菜单（最高层级，保证阅读）   |
| `--glass-card`    | `rgba(255,255,255,.65)` | 内容卡片、消息气泡、思考块、输入区       |
| `--glass-nav`     | `rgba(255,255,255,.45)` | 侧边导航、顶栏                 |
| `--glass-sunken`  | `rgba(255,255,255,.30)` | 凹陷区：控制台、代码块、日志底、未激活开关   |

- 悬浮态：叠底透明度 +0.08；按下态 +0.04；描边不变。
- 滚动长列表内的卡片禁用 blur（渲染性能），改用静态版 `--glass-card-static`（同构造去 blur，叠底提至 .80）。
- `prefers-reduced-transparency` 或 GPU 降级时：全部玻璃面替换为实底 `--glass-fallback: #FBF3EE`，层级改由 1px `--line` 描边表达。

#### 2.1.4 派生中性色（暖墨阶，与主色同暖调派生）

| Token           | 色值                    | 使用场景                          |
| --------------- | --------------------- | ----------------------------- |
| `--ink-title`   | `#2F2423`             | 标题、重要图标、强调文字                  |
| `--ink-body`    | `#4A3A38`             | 正文                            |
| `--ink-soft`    | `#6E5B58`             | 次级文字：描述、表单项标签、导航未选中项          |
| `--ink-faint`   | `#9C8B87`             | 占位符、时间戳、禁用态（仅限 12px 辅助文字）     |
| `--line`        | `rgba(47,36,35,.10)`  | 卡片内分割线、表格线                    |
| `--brand-strong`| `#934141`             | 主色 hover 加深态、浅主色底上的文字         |
| `--brand-soft`  | `#F0D9D9`             | 主色浅底：选中导航背景、标签底、hover 态       |
| `--brand-faint` | `#F8ECEC`             | 大面积浅主色底：空状态插画底、推荐卡片           |

#### 2.1.5 语义色（仅状态语义）

| 语义         | 主色        | 浅底        | 使用场景           |
| ---------- | --------- | --------- | -------------- |
| 成功 Success | `#2E7D46` | `#E2F3E6` | 投递成功、余额正常、任务完成 |
| 警示 Warning | `#B45309` | `#FBF0DC` | 配额将尽、待处理提醒     |
| 危险 Danger  | `#DC2626` | `#FCE9E9` | 删除、不可撤销操作、错误提示 |

- 语义色文字/图标永远搭配同语义浅底使用，禁止大面积铺为背景。
- **危险色与主色同为红相**，区分靠饱和度与明度：主色砖红是哑光陶土感，危险色是高饱和正红。禁止用主色表达错误态，也禁止用危险色做品牌强调。

#### 2.1.6 叠加与焦点

- 遮罩：`rgba(46,28,24,.32)`，弹窗/抽屉专用，压暗背景同时保留渐变隐约可见。
- 焦点环：`0 0 0 3px rgba(179,79,79,.35)`（砖红 35%）。
- 纯白 `#FFF` 只允许两种用途：玻璃叠底、主色/语义深底上的文字与图标；除此之外不作为表面色。
- 纯黑 `#000` 禁用，最深处用 `--ink-title`。
- 所有派生颜色必须经 CSS token 引用，**禁止硬编码 hex**。

#### 2.1.7 颜色使用约束

- 对比度：正文 / 承载底 ≥ 4.5:1（按玻璃叠底叠加渐变后的有效底色计算）；大字标题 ≥ 3:1。
- 砖红 `#B34F4F` 可直接作文字色（有效浅底上对比度 ≥ 4.5:1）；`--brand-soft` 等浅主色底上的文字用 `--brand-strong`。
- 阴影统一暖墨基色 `rgba(58,34,30, α)`，禁止灰色或黑色阴影。
- 主按钮 = 砖红底 + 白字；一屏只允许一个主按钮。

### 2.2 字体规范

#### 2.2.1 字体家族（共 4 个，不得新增）

| Token          | 字体                                              | 用途                                                        |
| -------------- | ----------------------------------------------- | --------------------------------------------------------- |
| `--font-serif` | Noto Serif SC / Source Han Serif SC / Songti SC | 页面标题、区块标题（界面气质的核心）                                        |
| `--font-sans`  | Noto Sans SC / PingFang SC / Microsoft YaHei    | 正文、按钮、表单、导航等一切 UI 文字（默认字体）                                |
| `--font-mono`  | JetBrains Mono / Cascadia Mono / Consolas       | 代码、Token 用量、ID、等宽数字（`font-variant-numeric: tabular-nums`） |
| `--font-brand` | Playwrite DE LA Guides                          | 仅 "OfferGet" 品牌字标，**禁止用于任何其他文案**                          |

> 旧版 Nunito 仅限遗留开发者控制台沿用，新界面一律不再引入，随重构退役。

#### 2.2.2 字阶（Type Scale）

| 层级        | 字号 / 行高 | 字重  | 字体    | 使用场景                                          |
| --------- | ------- | --- | ----- | --------------------------------------------- |
| Display   | 32 / 40 | 600 | Serif | 启动页、空状态主视觉标题                                  |
| 页面标题      | 24 / 32 | 600 | Serif | PageHeader 的 h1                               |
| 区块标题      | 18 / 26 | 600 | Serif | 卡片组标题、抽屉/弹窗标题                                 |
| 卡片标题      | 16 / 24 | 600 | Sans  | 卡片标题、列表主行                                     |
| 正文        | 14 / 22 | 400 | Sans  | 默认正文、按钮、输入框                                   |
| 紧凑正文      | 13 / 20 | 400 | Sans  | 导航项、表格、列表次级行                                  |
| 辅助文字      | 12 / 18 | 400 | Sans  | 描述、时间戳、表单 hint                                |
| 标签 Kicker | 11 / 16 | 500 | Sans  | eyebrow、徽标、分组标签；大写场景加 `letter-spacing: .12em` |
| 等宽        | 12 / 18 | 400 | Mono  | 代码、用量数字、日志                                    |

#### 2.2.3 排版约束

- 字重只用 400 / 500 / 600 三档；Serif 标题不使用 700 以上。
- 中文正文行长控制在 28–48 字；阅读型栏宽容器最大 `720px`。
- 数字一律等宽对齐（表格、余额、Token 统计必须 `tabular-nums`）。
- `letter-spacing` 只允许出现在 11px Kicker（.12em）与品牌字（-.01em），正文不拉开字距。

### 2.3 网格与布局规范

#### 2.3.1 应用框架（桌面窗口）

| 区域     | 规格                                                              |
| ------ | --------------------------------------------------------------- |
| 基准窗口   | 1280 × 800；最低发布验收窗口 1024 × 680（更小尺寸仅作降级适配，不承诺完整工作台能力）          |
| 侧边栏    | 默认 224px，可拖拽范围 192–320px；收起态 56px（仅图标）；整栏使用 `--glass-nav`     |
| 主内容区   | 最小宽 720px；求职助手场景最小 480px；内容区自身不透明，透出根层渐变                      |
| 顶栏     | 高 56px，`--glass-nav` 底 + 下方 1px `--line` 分隔线                     |

#### 2.3.2 内容网格

| 项目          | 规格                                               |
| ----------- | ------------------------------------------------ |
| 列数          | 12 列（内容区 ≥ 1080px 时）；6 列（720–1080px）；单列（< 720px） |
| 水槽 Gutter   | 24px                                             |
| 页面边距 Margin | 32px；窗口 ≥ 1440px 时增至 48px                        |
| 内容最大宽       | 阅读型 720px；工作台型 1120px；超过后居中，不再拉宽                 |
| 卡片栅格        | 卡片列表按 12 列均分：3 卡/行（各 4 列）、4 卡/行（各 3 列），水槽 24px   |

#### 2.3.3 间距刻度（Spacing Scale）

只允许使用 4px 基数的刻度：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 图标与文字间：4 或 8
- 控件内部 padding：8 / 12 / 16
- 卡片内边距：20（紧凑）或 24（标准）
- 卡片之间：16（列表）或 24（栅格）
- 页面区块之间：32 或 48
- **禁止出现 5、7、9、10、13、14 等非刻度值**（旧源码中的非刻度圆角与间距需逐步归位）。

### 2.4 图标规范

#### 2.4.1 技术形态

- 统一使用 Iconfont 集合 16880 的 PNG 资源 + CSS mask 方案，颜色继承 `currentColor`，随场景自动适配暖墨阶/主色/语义色。
- 新增图标必须来自同一集合，保持一致的描边粗细与圆头风格；禁止混入 emoji、彩色 SVG、其他图标库。

#### 2.4.2 尺寸刻度（仅 4 档）

| 尺寸  | 使用场景                     |
| --- | ------------------------ |
| 12  | Kicker 标签内、徽标角标（尽量少用）    |
| 16  | 导航项、菜单项、行内操作（重命名/删除）、表单内 |
| 20  | **默认尺寸**：按钮内、顶栏工具、卡片头部   |
| 24  | 空状态、功能入口大卡、启动页           |

#### 2.4.3 使用约束

- 同一容器内图标必须同一尺寸档位，垂直居中（flex `align-items: center`）。
- 图标与文字间距固定 8px（紧凑场景 4px）。
- 可点击图标必须有 32×32 的最小热区（可用透明 padding 扩展）。
- 图标默认取 `--ink-soft`，激活/强调取 `--brand` 或 `--ink-title`，禁止彩色图标（DeepSeek 品牌色除外，属第三方标识）。

### 2.5 模块规范

#### 2.5.1 圆角刻度（仅 5 档）

| Token              | 值   | 使用场景               |
| ------------------ | --- | ------------------ |
| `--radius-mark`    | 4   | 小标签、徽标、色块标记        |
| `--radius-control` | 8   | 按钮、输入框、下拉、导航项、小菜单项 |
| `--radius-card`    | 12  | 卡片、消息气泡、思考块        |
| `--radius-overlay` | 16  | 弹窗、抽屉、用户浮层         |
| `--radius-pill`    | 999 | 开关、进度条、滚动条、胶囊标签    |

品牌特例：`brand-mark` 使用 `9px 9px 4px 9px` 的不对称圆角，仅限 Logo 图形，不扩散。

#### 2.5.2 核心组件规格

| 组件        | 规格                                                                                          |
| --------- | ------------------------------------------------------------------------------------------- |
| 主按钮       | 高 36，padding `0 16`，圆角 8，砖红底 `#B34F4F` + 白字，hover 用 `--brand-strong` + 上浮阴影 `--shadow-raised` |
| 次按钮       | 高 36，圆角 8，`--glass-card` 底 + 1px 玻璃描边 + `--ink-title` 字                                          |
| 危险按钮      | 同次按钮结构，文字与描边用 Danger `#DC2626`，浅底 `#FCE9E9`                                                     |
| 输入框 / 下拉  | 高 40，圆角 8，padding `8 12`，`--glass-card` 底，聚焦时 3px 砖红焦点环                                       |
| 多行输入      | `line-height: 28`，最小 3 行                                                                     |
| 卡片        | 圆角 12，`--glass-card` + blur(16px) + 1px 玻璃描边，padding 24（紧凑 20）                                |
| 导航项       | 高 34，圆角 8，图标 16 + 文字 13/20；选中态 = `--brand-soft` 底 + `--brand-strong` 字 + 左侧 3px 砖红标记              |
| 弹窗 Modal  | 圆角 16，宽 480（表单类 560），`--glass-overlay` 底 + 32% 遮罩                                                |
| 抽屉 Drawer | 圆角 16（左缘），宽 420，右侧滑入，`--glass-overlay` 底                                                      |
| 开关 Switch | 32 × 18，圆角 999，未激活 `--glass-sunken`，激活底 = 砖红                                                   |
| 空状态       | 图标 24（`--ink-faint`）+ Display 衬线标题 + 14 辅助描述，可叠 `--brand-faint` 浅底                              |

#### 2.5.3 阴影刻度（暖墨基色 `58,34,30`）

| Token              | 值                   | 场景            |
| ------------------ | ------------------- | ------------- |
| `--shadow-surface` | `0 2px 8px / .06`   | 卡片、顶栏工具       |
| `--shadow-raised`  | `0 3px 14px / .09`  | 悬浮卡片、hover 抬升 |
| `--shadow-overlay` | `0 13px 34px / .17` | 弹窗、抽屉、浮层菜单    |
| `--shadow-control` | `0 1px 3px / .25`   | 开关滑块等小控件      |

#### 2.5.4 动效

- 标准过渡 `160ms ease`；浮层展开 `180–220ms ease`。
- 可动画属性仅限 `transform / opacity / background / box-shadow`，禁止动画 `width / height / top / left`。
- 页面级不做转场动画；抽屉/浮层沿进场方向位移 10px 内淡入。
- `backdrop-filter` 不参与过渡动画（性能与闪烁风险），玻璃面切换透明度时只动 `background-color`。

## 三、设计约束（Do / Don't）

### 3.1 硬约束（违反即退回）

1. **颜色**：只允许 1 主色 + 派生 token + 3 组语义色；纯黑 `#000` 禁用（最深处用 `--ink-title`）；纯白仅限玻璃叠底与深底文字。所有颜色必须经 CSS token 引用，禁止硬编码 hex。
2. **表面**：所有卡片、导航、浮层必须使用四档玻璃 token，禁止不透明实底卡片（降级兜底 `--glass-fallback` 除外）；背景渐变只允许出现在窗口根层，禁止局部另铺渐变或实底。
3. **红相分工**：砖红只代表品牌与选中态，正红 `#DC2626` 只代表危险/错误；二者禁止互换或同时使用于相邻元素。
4. **字体**：只允许 4 个字体家族与 9 档字阶；品牌手写字仅用于 Logo；Nunito 不再进入新界面。
5. **间距/圆角/图标**：只用既定刻度；新增组件前先查刻度表，查不到才允许扩展（并在本文件登记）。
6. **主色克制**：砖红强调在单屏出现不超过 3 处；一屏只有一个主按钮。
7. **可访问性**：正文对比度 ≥ 4.5:1（按玻璃有效底色）；可点热区 ≥ 32×32；焦点环不可移除；`prefers-reduced-motion` 时关闭非必要动效；`prefers-reduced-transparency` 时玻璃面降级为实底。

### 3.2 软约束（评审关注点）

- 优先用"透明度差 + 1px 玻璃描边"分层，慎用阴影；同一视口阴影层级不超过 2 层。
- 同屏 `backdrop-filter` 层数控制在 12 层以内；滚动容器内卡片一律用 `--glass-card-static`。
- 长列表、日志、控制台等密集信息场景用 `--glass-sunken` 凹陷底收敛视觉，而非加边框。
- 文案语气：简短、礼貌、确定；按钮用动宾短语（"保存""投递""新建会话"），不用"好的""确定"。
- 第三方品牌元素（DeepSeek 标识等）保留其原始色彩，不套用主色。

### 3.3 迁移路线（源码向本规范收敛）

1. `tokens.css` 整体换板：accent 系列改为砖红，ink 系列改为暖墨阶，focus-ring 同步换色；新增 `--bg-sky`、四档 `--glass-*`、`--glass-card-static`、`--glass-fallback`。
2. 窗口根层铺设固定渐变，移除各页面与卡片的不透明底色。
3. 卡片、侧边栏、顶栏、浮层切换为玻璃 token；圆角、间距、字体刻度不变，布局结构无需改动。
4. 开发者模式界面最后迁移，期间允许保留旧字体与灰阶，但主色必须先换板。
